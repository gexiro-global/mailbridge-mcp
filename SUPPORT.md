# Support

## Usage questions

Use GitHub Discussions or open a narrowly scoped issue with the provided form.
Include the MailBridge version, Node.js version, operating system, expected
behavior, and a minimal reproduction using synthetic data.

## Security reports

Follow [SECURITY.md](SECURITY.md). Never place credentials, real email, private
hostnames, tokens, or unredacted logs in an issue.

## Scope boundary

This repository supports the synthetic reference distribution. Private IMAP
deployments, credential migration, production hosting, and vendor-specific
mailbox configuration are outside its public support scope.
