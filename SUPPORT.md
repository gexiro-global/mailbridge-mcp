# Support

Use GitHub Discussions or a focused issue with the MailBridge version, Node.js
version, operating system and a minimal reproduction using synthetic data.

Community support covers the self-hosted connector, generic IMAP/SMTP, OAuth
resource-server configuration and the supplied container. Provider-specific
account policy, OAuth client approval, DNS, reverse proxy and infrastructure
operations remain the deployer's responsibility.

Never put credentials, real email, tokens, private hostnames, database files or
unredacted logs in an issue. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.
